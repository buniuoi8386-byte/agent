01 / 概览

让多路信息，
汇成一份简报。

帮助读者快速了解发生了什么、为何值得关注，以及可以去哪里核对，而不必逐篇打开报道或听完整段长音频。

每条新闻标注主题、发布时间、原始出处与核验状态。证据不足的紧急消息会单独标记，不会被写成已确认事实。

03 / 工作方式

从信息线索，
到可信简报。

依据影响力与证据筛选，不以浏览量决定重要性。

01

接收内容

读取网址、报道、文档，或用户提供的音频与视频内容。

来源可追溯
02

分类并核验

检查来源、发布日期、事件发生时间、上下文及不同来源之间的独立性。

必须 · 不作猜测
03

筛选重要消息

按影响、时效、可信度与读者价值排序，并合并重复报道。

质量优先
04

编辑并注明出处

概括事件、相关主体、时间、证据与影响，附上原始链接和核验状态。

信息可追溯
05

复核并交付

检查准确性、中立性、重复内容与版式；遇到敏感或矛盾消息时暂停并请求人工判断。

设有安全停点

05 / 能力边界

了解 Agent 能做什么，
以及何时需要暂停。

✓

设计目标

  • 汇总教育、科技与 AI、经济、社会及时事新闻。
  • 保留原始链接、发布时间与核验状态。
  • 识别重复报道、转引来源与相互矛盾的信息。
  • 将未核实的紧急消息单独标注并明确提示。
!

当前限制

  • 不保证能读取登录后、付费墙内或所有平台的内容。
  • 音视频转写与分析能力尚未经过充分验证。
  • 私聊接收曾发现 ID 不匹配；修正后仍待确认测试结果。
  • 每日 07:00 与周日 19:00 的自动发送任务尚未设置。
⛨

安全边界

  • 不编造事实、数据、引述或来源。
  • 不把推测、预测或未核实消息写成事实。
  • 未被选定并配置的 Lark 群组不会纳入处理。
  • 本页面不包含密钥、权限、私密数据，也没有调用 Agent 的接口。
