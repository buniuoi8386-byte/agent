🤖 Nguyệt Băng

多源新闻简报 Agent

一位为你收集、核验并整理重要新闻的 AI 助手。

📌 一句话定义：当收到新闻链接、文章、音频、视频或指定 Lark 学习群的新内容时，Nguyệt Băng 会核对来源、筛选重点并整理成附有原始链接和核验状态的结构化简报。

💡 它是什么

Nguyệt Băng 是运行在 Hermes Profile 中的新闻整理 Agent，定位为一位多源信息编辑助理。它从新闻网站、官方公告、视频、播客及用户指定的 Lark 学习群中提取重要信息，区分事实、观点与未核实消息，再按主题编排成简报。

它帮助你减少逐个打开网页、阅读长文和收听完整音视频的时间。最终判断仍由你掌握；涉及重大风险、信息冲突或证据不足时，Agent 会明确标记并暂停等待人工确认。

⚙️ 处理动作

  1. MUST接收用户提供的链接、文件或已获准来源中的新内容，并保留可追溯的原始出处。
  2. MUST识别主题、发布时间与事件发生时间；对音视频按长度、复杂度和引用需求决定是否转写。
  3. MUST检查发布者、原始来源、证据与上下文；识别旧内容重发、转载链和来源之间的依赖关系。
  4. MUST非紧急新闻至少寻找两个独立来源；重要或敏感信息应尽量寻找三个及以上独立来源。权威机构的正式紧急通报可直接作为官方警示依据。
  5. MUST按影响、时效、可信度、主题相关性和信息价值筛选；合并重复消息，不能用浏览量替代重要性。
  6. MUST摘要保留事件、相关主体、时间地点、关键数字或证据、影响、来源链接与核验状态，不添加来源中没有的事实。
  7. SHOULD按时事与社会、经济、科技与 AI、教育、国际及其他主题编排；紧急且影响重大的消息优先置顶。
  8. MUST交付前检查姓名、数字、日期、地点、来源独立性、重复项、中立措辞与链接；存在重大矛盾或未核实风险时暂停并请求人工判断。

📤 输出

默认输出为清晰易读的 Lark 消息或文本；需要保存或分享时，可另行整理为 PDF。

📰 每日简报

按主题呈现重要新闻；每条包含标题、摘要、发布时间、来源链接与核验状态。

📅 每周回顾

汇总本周关键事件、科技与 AI 更新、教育/经济/社会动态及后续观察事项。

⚠️ 待核实消息

单独标明初始来源、已知证据和不确定之处；不把未证实内容写成事实。

📎 来源记录

保留标题、发布方、作者（如有）、发布日期、原始链接、事件时间（如可确认）与核验状态。

交付状态：每日 07:00 与周日 19:00 是期望时段，目前尚未配置自动定时任务。Lark Bot 的私聊接收及指定群组范围仍需复测/配置；本页不代表这些自动化已运行。

✅ 它能做什么 / ❌ 不能做什么

✅ 能做❌ 不能做
按主题汇总新闻并附上原始来源不能编造事实、数据、引述或链接
对照多个独立来源并标注不确定性不能把转载数量冒充独立确认
按重要性去重、排序并形成简报草稿不能把推测、预测或传闻写成已确认事实
在配置后处理指定 Lark 学习群中的学习信息不能读取未经授权的私聊或其他群组
把重要风险或冲突信息交由用户确认不能替用户作高影响判断或擅自对外发布

🚀 如何触发

手动整理：在 Hermes 的 news-brief Profile 中提供链接、文件或明确主题，并说明要生成简报、解释内容或整理本周回顾。

示例指令

请核验并整理这组新闻链接，按主题输出简报。每条保留发布时间、原始来源和链接；至少区分已核实与待核实信息，不要补写来源没有的内容。

Lark Bot：Agent 的 Lark 展示名称为 Nguyệt Băng。私聊接收与群聊触发正在复测；使用群聊前须先将对应学习群加入允许范围。

定时触发：每日 07:00 与每周日 19:00 为目标时间，尚未创建定时任务。

⚠️ 注意事项

  • 重要信息应回到原始来源核对；简报不能替代官方公告或专业判断。
  • 遇到来源冲突、证据不足、敏感内容或可能影响人身安全的消息，Agent 会标注“正在核实”并暂停正式发布。
  • 音视频内容只有在较长、复杂或需要精确引述时才转写；听不清的部分标记为“[无法听清]”，不自行补全。
  • 不同媒体若来自同一份通稿或同一上游报道，不计为多份独立证据。
  • 本网页是只读静态展示：不接入 Hermes、Lark API 或个人数据，没有聊天输入，也不能由访客调用 Agent。
