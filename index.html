📰 Nguyệt Băng · 多源新闻 📘 Tuần An · 学习周报

📌 一句话定义：当收到新闻链接、文章、音频、视频或已授权来源的新内容时，Nguyệt Băng 会核对来源、筛选重点并整理成附有原始链接和核验状态的结构化简报。

💡 它是什么

Nguyệt Băng 是运行在独立 Hermes Profile 中的多源新闻助理。它从新闻网站、官方公告、视频、播客及用户明确提供或已授权的来源中提取重要信息，区分事实、观点与未核实消息，再按主题编排成简报。

它帮助你减少逐个打开网页、阅读长文和收听完整音视频的时间。最终判断仍由你掌握；涉及重大风险、信息冲突或证据不足时，助理会明确标记并暂停等待人工确认。

⚙️ 处理动作

  1. MUST接收用户提供的链接、文件或已获准来源中的新内容，并保留可追溯的原始出处。
  2. MUST识别主题、发布时间与事件发生时间；对音视频按长度、复杂度和引用需求决定是否转写。
  3. MUST检查发布者、原始来源、证据与上下文；识别旧内容重发、转载链和来源之间的依赖关系。
  4. MUST非紧急新闻至少寻找两个独立来源；重要或敏感信息应尽量寻找三个及以上独立来源。权威机构的正式紧急通报可直接作为官方警示依据。
  5. MUST按影响、时效、可信度、主题相关性和信息价值筛选；合并重复消息，不能用浏览量替代重要性。
  6. MUST摘要保留事件、相关主体、时间地点、关键数字或证据、影响、来源链接与核验状态，不添加来源中没有的事实。
  7. SHOULD按时事与社会、经济、科技与 AI、教育、国际及其他主题编排；紧急且影响重大的消息优先置顶。
  8. MUST交付前检查姓名、数字、日期、地点、来源独立性、重复项、中立措辞与链接；存在重大矛盾或未核实风险时暂停并请求人工判断。

📤 输出

默认输出为清晰易读的 Lark 消息或文本；需要保存或分享时，可另行整理为 PDF。

交付状态：每日 07:00 与周日 19:00 是期望时段，目前尚未验证自动定时任务。本展示不代表任何定时发送或 Lark 收发自动化已经运行。

✅ 能做❌ 不能做

🚀 如何触发

手动整理：在 Hermes 的 news-brief Profile 中提供链接、文件或明确主题，并说明要生成简报、解释内容或整理本周新闻回顾。

示例指令

请核验并整理这组新闻链接，按主题输出简报。每条保留发布时间、原始来源和链接；至少区分已核实与待核实信息，不要补写来源没有的内容。

Lark 渠道：Nguyệt Băng 是 Hermes 中运行的 AI 助理，Lark 只是可选消息渠道。自动收发方式尚未验证；请以 Hermes 当前实际连接状态为准。

定时触发：每日 07:00 与每周日 19:00 为目标时间，尚未创建定时任务。

⚠️ 注意事项

  • 重要信息应回到原始来源核对；简报不能替代官方公告或专业判断。
  • 遇到来源冲突、证据不足、敏感内容或可能影响人身安全的消息，助理会标注“正在核实”并暂停正式发布。
  • 音视频内容只有在较长、复杂或需要精确引述时才转写；听不清的部分标记为“[无法听清]”，不自行补全。
  • 不同媒体若来自同一份通稿或同一上游报道，不计为多份独立证据。
  • 本网页是只读静态展示：不接入 Hermes、Lark API 或个人数据，没有聊天输入，也不能由访客调用助理。

学习周报助理 · Profile: weekly-report

把本周已提供或已授权的课程资料和任务记录整理成可核对的学习周报。

📌 一句话定义：当收到一周的课程通知、学习资料、任务清单或进度记录时，Tuần An 会提取并核对事实，归并重复事项，输出包含完成情况、待办、截止日期和下周重点的学习周报。

💡 它是什么

Tuần An 是独立 Hermes Profile weekly-report 中的个人学习助理。它只处理用户提供或明确授权的资料，帮助回顾本周学习事项并规划下一周。它与 Nguyệt Băng 是两个不同的 Profile：一个整理学习周报，一个整理多源新闻。

本展示页是只读介绍，不会读取个人课程记录。没有输入的学习成果不会被推测或编造。

⚙️ 标准工作流程

  1. MUST接收输入并确认报告周期、课程范围及来源是否在授权范围内；超范围资料不读取。
  2. MUST提取课程、任务、截止日期、状态、通知、资料和出处；保留文件名、时间戳或链接以便回查。
  3. MUST合并重复任务，区分明确事实、用户自述和待确认信息；来源相互冲突时保留差异。
  4. MUST只按输入证据标记已完成/进行中/未完成；缺少状态或日期时标记“待确认/未提供”。
  5. SHOULD归纳本周完成、未完成、重要资料与通知、需要确认的事项及下周优先任务。
  6. MUST复核日期、课程、任务状态、来源、重复项、矛盾和隐私；不编造学习成果或计划。
  7. MUST按用户指定格式交付；只有真实写入或发送成功后才报告已保存/已发送。

请根据我发来的本周课程通知、任务和笔记，生成学习周报。逐项保留来源和截止日期；完成状态不明确的标记待确认；最后按紧急程度列出下周待办。不要访问其他群或补写未提供的信息。

定时与 Lark：周日 19:00 是期望时间，不代表定时任务已安装。若要使用自动读取或发送，需要先配置明确的授权范围并完成端到端测试。
